# (Upgrade From Buster to Bookworm)
## Run Script :
### 1- First run the script to update from `Buster` to `bullseye` then script will reboot automatically.
### 2- Again run the script second time to update from `bullseye` to `bookworm`. 

## How to Run Script:
Let's assume script available in desktop of raspi so open the terminal and get directory to desktop where script exist. 
 
  1-   `cd /Desktop`
  
  2-   `sudo python3 upgrade_raspberry_pi.py`

Note: During run script you need to give command or press y to continue process.
